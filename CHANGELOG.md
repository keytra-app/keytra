## [0.1.0] - 2026-11-26

### Added

- Projects with source and target locales and namespaced translation keys.
- Web translation editor with status filters, search, reference locales, placeholder checks and keyboard shortcuts.
- Automatic `outdated` status when a source text changes.
- JSON import with preview and JSON/ZIP export.
- Admin and translator roles, invite links and per-project access.
- REST API (`push`, `pull`, `status`) with per-project API keys, and a health endpoint.
- Docker image and Docker Compose setup with automatic database migrations.
