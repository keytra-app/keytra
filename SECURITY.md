# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

**Do not open a public issue, discussion or pull request.**

Report it privately through GitHub Security Advisories:
<https://github.com/keytra-app/keytra/security/advisories/new>

Include:

- the affected version or image tag,
- steps to reproduce or a proof of concept,
- the impact you expect.

Remove real credentials, API keys and personal data from your report.

We aim to acknowledge reports within 7 days. Please give us time to release a fix before you disclose the issue. We credit reporters in the advisory unless you prefer otherwise.
